# Как внести вклад

## Чем можно помочь

- Сообщить о баге — Issues
- Улучшить переводы — PR с правкой `js/locales/*.json`
- Уточнить таблицы оружия — PR с правкой `config/weapons.js`
- Добавить/уточнить вышки — `config/app.js`
- Star — поддержка проекта

## Стиль кода

- Модули — IIFE с экспортом в `window.*`, без внешних зависимостей
- Чистые функции — в `js/core/`, без доступа к DOM
- Конфигурация — только в `config/`, без хардкода в логике
- Переводы — только в `js/locales/*.json`

## Pull Request

1. Fork и ветка от `main`
2. Один PR — одна задача
3. Коммиты в стиле: `feat:`, `fix:`, `refactor:`, `docs:`, `i18n:`
4. Проверь локально через локальный сервер (не `file://`)
