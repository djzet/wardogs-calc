# Функции и оружие

## Возможности

- Интерактивная карта 16×16 км: тайловый зум, pan, canvas-рендерер
- Точки A/B: ПКМ / long-press, drag & drop, ручной ввод в %
- Мгновенный расчёт: дистанция, азимут, elevation (mils), время подлёта
- Два орудия: миномёт (до 700 м) и артиллерия (до 2.5 км)
- Круг дальности выбранного орудия
- Иконки вышек с тултипами (переключается в drawer)
- Share-ссылки с координатами и оружием
- Автосохранение точек, оружия, темы и камеры
- 9 языков с мгновенным переключением
- Тёмная / светлая тема
- Мобильная версия: pinch-zoom, long-press меню

## Как считается

- **Азимут** — `atan2(dx, dy)`, по часовой от севера (0° = N)
- **Elevation** — линейная интерполяция между точками таблицы,
  снап к шагу прицела (миномёт: 50, артиллерия: 10)
- **Время подлёта** — `t = d / (v₀ · cos θ)`, θ — угол возвышения в радианах
- **Карта** — canvas-рендерер с пирамидой тайлов `zoom_0…zoom_5`,
  LRU-кэш (500 тайлов), HiDPI-поддержка

## Статусы расчёта

| Статус       | Сообщение                        |
| ------------ | -------------------------------- |
| `coincide`   | точки совпадают                  |
| `tooClose`   | слишком близко (меньше minRange) |
| `outOfRange` | вне досягаемости                 |
| `ok`         | показаны mils и время            |
