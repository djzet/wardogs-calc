# 🎯 WARDOGS — Mortar Calculator

Одностраничный калькулятор миномётного расчёта для игры WARDOGS.

## Возможности

- Интерактивная карта 16 × 16 км (тайлы) с сеткой в метрах
- Расчёт дистанции, азимута, угла возвышения и времени подлёта
- 5 смотровых вышек с реальными координатами; клик по вышке — её название
- ПКМ — установка точек, ЛКМ — перемещение, колесо — масштаб
- 9 языков интерфейса
- Тёмная и светлая темы
- Точки, вид карты и настройки сохраняются в localStorage

## Управление

| Действие | Управление |
|---|---|
| Поставить / удалить точку | ПКМ по карте |
| Двигать карту или точку | ЛКМ |
| Масштаб | Колесо мыши |
| Название вышки | Клик по вышке |
| Дополнительные настройки | Кнопка-гамбургер рядом с заголовком |

Неофициальный фан-инструмент, не аффилирован с разработчиками WARDOGS.

# 🎯 WARDOGS — Mortar Calculator

A single-page mortar calculation calculator for the game WARDOGS.

## Features

- Interactive 16 x 16 km map (tiles) with a grid in meters
- Calculates distance, azimuth, elevation, and flight time
- 5 watchtowers with real-world coordinates; click on a watchtower to display its name
- Right-click to place waypoints, Left-click to move, and the mouse wheel to zoom
- 9 interface languages
- Dark and light themes
- Waypoints, map view, and settings are saved in localStorage

## Controls

| Action | Controls |
|---|---|
| Place/Delete Waypoint | Right-click on the map |
| Move the map or waypoint | Left-click |
| Zoom | Mouse wheel |
| Tower name | Click on the tower |
| Additional settings | Hamburger button next to the title |

Unofficial fan tool, not affiliated with the WARDOGS developers.
